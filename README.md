# REKAA - AI-Powered Medical Dashboard 🏥🤖

**REKAA** (Real-time Emergency Knowledge & Assistance Agent) is a cutting-edge hospital triage system that combines **Generative AI** with **3D Visualization** to provide instant medical guidance and indoor navigation.

## 🔥 Key Features
- **Gemini AI Brain:** Real-time symptom analysis using Google's Gemini 1.5 Flash.
- **3D Avatar Interaction:** A fully responsive 3D assistant with audio-reactive lip-sync.
- **Smart Navigation:** Google Maps-style 2D indoor navigator that generates paths to departments (ER, OPD, Cardiology) dynamically.
- **Multilingual Support:** Handles both Hindi and English for diverse patient needs.
- **Digital Triage Slip:** Automatically generates tokens and slips based on AI diagnosis.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Modern Glassmorphism UI)
- **AI/LLM:** Google Generative AI (Gemini API)
- **3D Engine:** Three.js (WebGL)
- **Voice Logic:** Web Speech API (Multilingual TTS/STT)
